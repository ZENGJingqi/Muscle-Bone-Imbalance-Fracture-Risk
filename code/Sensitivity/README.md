# Sensitivity Analyses

This folder contains public scripts for sensitivity analyses that support the external validation workflow.

The scripts are intentionally limited to statistical modeling and diagnostic-performance summaries. They do not generate manuscript text, Word documents, submission files, or local writing records.

## Scripts

- `run_survey_weighted_sensitivity.R`: survey-weighted NHANES and KNHANES sensitivity models using the processed analytic files generated by the dataset-specific scripts.
- `run_rcs_threshold_performance.R`: restricted cubic spline checks and threshold-performance summaries for external DXA-derived MBR analyses.

## Expected Inputs

The scripts assume that the following processed files have already been created:

- `data/processed/NHANES/NHANES_2013_2014_outcome_bundle.csv.gz`
- `data/processed/NHANES/NHANES_bridge_1999_2004_BIA_DXA.csv.gz`
- `data/processed/KNHANES/KNHANES_2008_2011_ALL_DXA_merged.rds`

## Expected Outputs

Outputs are written under:

```text
outputs/sensitivity/
  tables/
  figures/
```

Participant-level outputs should not be committed to this repository.
